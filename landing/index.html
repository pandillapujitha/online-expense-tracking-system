What you can do

  • Track everything

    Add, edit and delete expenses and income with categories, dates and notes.

  • Stay on budget

    Set a monthly limit per category. Bars turn amber at 80% and red when you overspend.

  • See the trend

    A six-month chart and a category breakdown show where your money is going.

  • Take your data

    Download every transaction as a CSV file for Excel or Google Sheets.

Cloud architecture

Three tiers, each of which can be scaled or replaced on its own.

Presentation

This HTML, CSS and JavaScript site plus the React single-page app. Can be hosted on a CDN or object storage.

Application

Stateless Node.js and Express REST API with JWT login. Packaged in Docker and run behind a load balancer using /api/health.

Data

JSON file store for the demo. Swap db.js for MongoDB Atlas, Amazon RDS or DynamoDB in production.
